# Guest functions where a hook needs the whole register state of the code that calls them
# (tools/recomp.py hook_list, read at every build; a change generates the C again).
#
# The register cache (tools/regcache.py) keeps guest registers in C locals and brings the Cpu
# context up to date only with what the ABI lets the other side read: before a call x0-x18,
# x29, x30 and SP; after it, x0-x18 and x30 are read back. So a hook that reads a caller's
# x19-x28 finds stale values there, and what it writes to x19-x28, x29 or SP is lost. An entry
# here changes that:
#
#   exact-callee <address> [<signature>] <name>
#       every direct call (bl) to the function stores every register the caller has changed
#       before the call and reads back every register the caller uses after it
#   exact-caller <address> [<signature>] <name>
#       every call the function makes (direct, indirect, svc) does the same
#
# A register the caller never writes holds what the context held when the caller was entered,
# which is exact only if that call was too. A call through a pointer (blr) cannot be known to
# reach an exact-callee: list its caller as an exact-caller. docs/TECHNICAL.md has the rest.
#
# <address>  where the function starts in game version 13.0.5, in main, subsdk0 or sdk (a
#            fighter module's address is each install's own)
# <signature>  optional: `<n> words, sha256 <16 hex digits>`, as `tools/recomp.py wrap-sig
#            <module> <address>` prints it for an HLE_WRAP; the build stops if the function
#            there does not begin that way
# <name>     what the function is, for people
#
# Addresses and names only: never instruction words (CONTRIBUTING.md, rule 1). The build stops
# at a line it cannot read, or at any 8-digit hex number, comments included.
#
# Empty for now. The hooks that need it (ssbu-recomp's loose files and new-fighter registry)
# add their entries when they are ported. Examples, with made-up addresses:
#
# exact-callee 7100001000 16 words, sha256 0123456789abcdef example_hooked_function
# exact-caller 7100002000 example_caller
